# BRONNEN_APA

## Inleiding
Dit document bevat de geraadpleegde literatuurbronnen voor het project **Slim Kasbeheer**. De lijst is opgesteld in **APA 7-stijl** op HBO-niveau en ondersteunt de netwerk- en IoT-onderdelen van het project (VLAN's, trunking, router-on-a-stick, ACL's, MQTT en TLS).

## Primaire bron (Opdrachtbeschrijving)
De opdrachttekst voor dit project is door de student zelf aangeleverd via de onderwijscontext en chatinstructie. Volgens APA-richtlijnen kan dit worden behandeld als persoonlijke communicatie of cursusmateriaal dat niet openbaar is.
