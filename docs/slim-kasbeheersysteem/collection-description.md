## Sprintverhaal (kort)
In deze sprint is eerst de netwerkanalyse uitgewerkt (@01_netwerkanalyse.md). Daarna is het IP-plan met segmentatie en ACL-beleid vastgelegd (@02_ip-plan-en-beveiliging.md). Vervolgens is de server/cloud-keuze onderbouwd (@03_server-en-cloud.md).

De uitvoering en validatie van de PoC is daarna gedocumenteerd met testresultaten en benodigde command outputs (@04_proof-of-concept.md). Tot slot zijn beheerprocedures uitgewerkt (@05_beheer-en-controle.md) en is een beknopt eindadvies opgesteld (@06_advies.md).
